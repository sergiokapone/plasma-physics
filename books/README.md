# Довідкові підручники з фізики плазми: що де шукати

Оглавления витягнуто з закладок djvu (`djvused -e print-outline`); якщо закладок нема (Арцимович, Биттенкорт, Ландау–Лифшиц, Милантьев, Ахиезер), оглавление береться з текстового шару. Нові книги: покласти djvu в цю теку і запустити `python -I make_toc.py` (створює лише відсутні TOC, існуючі не чіпає; `--list` показує стан, `--force` перезаписує). Для нової книги додай запис у `META` у `make_toc.py` (назва і ключ), інакше ключ береться з імені файлу. Файли `TOC_*.md` лежать поруч. Номер сторінки в `TOC_*.md` — **індекс сторінки djvu**, його ж приймає `djvu2png.py -p N`. Номер у книзі збігається з індексом, окрім Котельникова (книга = djvu − 1). Текстовий шар є в усіх файлах: `djvutxt --page=N файл.djvu` дає текст сторінки без картинки.

**Формати:** `.djvu` і `.pdf` (PDF через PyMuPDF: закладки, текст, PNG сторінки). PDF-скан без тексту: `search_books.py --ocr -b <книга>` (tesseract rus+ukr+eng, ~5 с/сторінку, результат кешується), потім `make_toc.py --force --only <книга>`. Скрипти спільно користуються `bookslib.py`; запускати `python -I`. Англійський оригінал Чена (`TOC_Chen-en.md`): §-номери збігаються з `chen2016introduction`.

## Як відкрити сторінку

```
djvutxt.exe --page=N "<файл>.djvu"                         текст сторінки
python D:\Programs\BookShop\Script\djvu2png.py "<файл>.djvu" -p N -o <тека> -s 60   сторінка як PNG
```
`djvutxt.exe` і `djvused.exe` у `D:\Programs\BookShop\DjVuLibre\`.
Під час виклику на Windows слід вживати Python з `-I`; шлях з кирилицею передавати з Python, а не з bash-глоба.

## Примітка про джерела

Ці підручники лежать лише як **довідкові**. У `bibliography/bibliography.bib` російськомовні книги не додаємо (правило користувача); для посилань у тексті використовуємо англійські аналоги (Chen, Introduction to Plasma Physics and Controlled Fusion; Stix; Krall–Trivelpiece тощо). Номери §§ з російського видання Чена можуть не збігатися з англійським.
