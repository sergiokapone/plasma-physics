# Топологія магнітного поля з X-точкою і «перез’єднання» у вакуумі: ТЗ для демонстрацій

Документ самодостатній: фізика, формули, перевірені числа та вимоги до реалізації.
Мова інтерфейсу й пояснень: українська. Система одиниць: **CGS (Гаусса)**.
Формат результату: окремі односторінкові HTML-файли (canvas, без зовнішніх бібліотек), у стилі інших симуляцій до курсу «Електрика та магнетизм».

---

## 0. Мета

Показати в курсі електромагнетизму (без плазми), що:

1. У вакуумі існують нулі магнітного поля, і єдина їхня стійка форма в 2D це X-точка (сідло).
2. Топологія силових ліній змінюється в часі при зміні струмів, і це повністю рахується з рівнянь Максвелла (Біо-Савар, Фарадей).
3. Аналог «вмороженості» дають кола з нульовим та ненульовим опором (збереження потоку).

Слово «перез’єднання» тут означає **зміну зв’язності картини силових ліній**, а не дрейф «ліній-об’єктів»: у вакуумі лінії індивідуальності не мають (див. розд. 7).

## 1. Фізична основа (2D, струми вздовж z)

### 1.1 Потік (векторний потенціал) і силові лінії

```
B = rot(A_z ẑ):   B_x = ∂A/∂y,   B_y = −∂A/∂x
∇²A = −(4π/c) j_z
```

Силові лінії це лінії рівня **A(x, y) = const**. Умова div B = 0 виконується автоматично.

Нескінченний тонкий дріт зі струмом I: `A = −(2I/c) ln r`, `B = (2I/(c r)) φ̂`.

Дріт радіуса ρ з рівномірним струмом (використовувати саме його, див. 2.1):

```
r ≥ ρ:  A = −(2I/c) ln r,                 B_φ = 2I/(c r)
r < ρ:  A = −(2I/c) ln ρ + (I/c)(1 − r²/ρ²),   B_φ = 2I r/(c ρ²)
```

### 1.2 Нулі й їх класифікація

Нуль: ∇A = 0. Матриця `M_ij = ∂B_i/∂x_j` = (поворот на 90°) · Гессіан A. Ознака за `det H`, де `H = Hess(A)`:

- `det H < 0`: **X-точка** (сідло); лінії поблизу `≈ y² − x² = const` у власних осях.
- `det H > 0`: **O-точка** (замкнені лінії).

У вакуумі (`∇²A = 0`) слід Гессіана нульовий, тому `det H ≤ 0`: **у вакуумі можливі лише X-точки**. O-точка вимагає `j ≠ 0` (теорема про циркуляцію: замкнена лінія навколо точки означає `∮B·dl = 4πI/c ≠ 0`). Тому O-точки сидять усередині провідників.

### 1.3 Комплексна форма (для лекції)

У вакуумі `f(z) = B_x − iB_y`, `z = x + iy`, аналітична функція (умови Коші-Рімана рівні div B = 0 і rot B = 0). Нулі поля це нулі f. Нуль порядку n: `f = c·zⁿ`, лінії мають `2(n+1)` секторів: n = 1 дає X (квадруполь), n = 2 секступоль.

### 1.4 Динаміка: закон Фарадея

У калібруванні φ = 0: `E_z = −(1/c) ∂A_z/∂t`. Абсолютне значення A_z визначене з точністю до сталої (калібрування), тому **фізичні лише різниці**. Швидкість зміни потоку в частині картини:

```
Φ_lobe = A_O − A_X          (потік на одиницю довжини між O-точкою та X-точкою)
E_z(X) − E_z(O) = (1/c) dΦ_lobe/dt
```

«Швидкість перез’єднання» = `dΦ_lobe/dt`.

Ідеальний закон Ома `E + (v × B)/c = 0` вимагає `E·B = 0` і не може виконуватися в нулі B = 0, де `E_z ≠ 0`. Саме тут «заморожені лінії» втрачають зміст.

## 2. Демонстрація A (основна): два паралельні струми, I₂ змінюється

### 2.1 Модель

- Дроти на осі x в точках **x = +a** (струм I₁, фіксований) і **x = −a** (струм I₂, повзунок), обидва вздовж +z.
- Радіус дротів **ρ**, рівномірна густина струму (формули 1.1). Нормування: **a = 1, I₁ = 1, c = 1** (або безрозмірні). За замовчуванням **ρ = 0,1 a**.
- Поле й потік: суперпозиція `A = A₁ + A₂`.
- Параметри інтерфейсу: I₂/I₁ ∈ [−1; 1] (повзунок, мілі-крок), ρ/a ∈ [0,03; 0,3], a (для демо B).

### 2.2 Аналітичні результати, які варто показати поруч із картинкою

**(а) Нитки (ρ → 0): положення нуля.** Умова рівності полів `I₁/d₁ = I₂/d₂`, `d₁ = a − x₀`, `d₂ = a + x₀`:

```
x₀ = a (I₂ − I₁)/(I₁ + I₂)
```

- I₂ = I₁: x₀ = 0 (центр).
- I₂ → 0⁺: x₀ → −a (нуль під дріт 2).
- I₂ < 0, |I₂| < I₁: x₀ < −a (нуль **ззовні**, за дротом 2); I₂ → −I₁: x₀ → −∞.

**(б) Рівні струми I₂ = I₁ = I:** розклад біля початку координат

```
B ≈ −(4I/(c a²)) · (y, x)          (квадруполь, g = 4I/(c a²), кут сепаратрис ±45°)
```

Сепаратриса (A = A_X) для ниток це **лемніската Бернуллі**:

```
(x² + y²)² = 2a² (x² − y²)
```

**(в) Потік петлі (рівні струми, a ≫ ρ):**

```
Φ_lobe = A_O − A_X ≈ (2I/c) [ ln(a/(2ρ)) + 1/2 ]
```

(Перевірено чисельно: a = 1, ρ = 0,1, I = c = 1: точне значення 4,2214, формула 4,2189.)

### 2.3 Що чисельно відбувається при зменшенні I₂ (перевірено, ρ = 0,1 a, I₁ = 1)

Нулі знайдені методом Ньютона з класифікацією за det H. Усі нулі лежать на осі x (y = 0).

| I₂/I₁ | X-точка (x) | O-точки (x) |
|---|---|---|
| 1 | 0 | −0,995 ; +0,995 |
| 0,5 | −0,3333 | −0,990 ; +0,998 |
| 0,2 | −0,6667 | −0,975 ; +0,999 |
| 0,1 | −0,8182 | −0,949 ; +0,9995 |
| 0,06 | −0,8868 | −0,913 ; +0,9997 |
| 0,05 | немає | +0,9997 |
| 0,02 … 0 … −0,02 | немає | +1,000 (лише O у дроті 1) |
| −0,05 | −1,105 | −1,095 ; +1,000 |
| −0,2 | −1,500 | −1,025 ; +1,001 |
| −0,5 | −3,000 | −1,010 ; +1,0025 |

Положення X збігається з формулою (а) для ниток (−0,3333; −0,6667; −0,8182; −1,5; −3,0).

### 2.4 Правильна інтерпретація (важливо)

Для **ниток** здається, що X-точка проходить крізь дріт 2. Для **дроту скінченного радіуса** картина інша:

1. Усередині дроту 2 (де `j ≠ 0`) живе **O-точка**: це зсунутий центр кільцевих ліній (у вакуумі її бути не може).
2. При зменшенні I₂ X-точка рухається до дроту, O-точка до неї назустріч. На порозі `I₂* ≈ I₁ρ/(2a − ρ)` (≈ 0,053 при ρ = 0,1) **X і O анігілюють** на поверхні дроту (сідло-вузлова біфуркація). Петля навколо дроту 2 зникає.
3. У проміжку `|I₂| ≲ I₁ρ/(2a)` поблизу дроту 2 нулів немає.
4. При I₂ < −I₁ρ/(2a + ρ) з протилежного боку дроту **народжується нова пара X + O** (X поза провідником, O біля його поверхні). Далі X іде в −∞ при I₂ → −I₁.

Топологічна зміна відбувається саме там, де нуль торкається області зі струмом, і лише через пару X–O (чисті X-точки у вакуумі не народжуються й не зникають поодинці).

### 2.5 Що показувати на екрані

- Силові лінії: ізолінії A (marching squares), рівномірно за A (≈ 25-40 ліній), густіше біля нулів не обов’язково.
- **Сепаратриса** (A = A_X) виділена кольором і товщиною. Якщо X немає, сепаратриси немає.
- Мітки: X (хрестик), O (кружечок), дроти як заповнені кола радіуса ρ зі знаком струму (⊙ / ⊗ за знаком).
- Показники: положення X і O, `I₂/I₁`, `Φ_lobe = A_O − A_X` для петель, `d(Φ_lobe)/dt` при автоматичній зміні I₂, `|B|` у нулі (контроль ≈ 0).
- Кнопки: «Пуск/Пауза» (автоматична зміна I₂ від +1 до −1 за ≈ 10 с), «Спочатку», перемикач «нитки / скінченний радіус».
- Опційно: кольорова карта |B| (логарифмічна) для наочності нулів.

### 2.6 Алгоритм (рекомендація)

1. Сітка ~ 400 × 200 на області x ∈ [−3; 3], y ∈ [−1,5; 1,5] (при I₂ < 0 X іде далеко: або розширити область, або обмежити I₂ ≥ −0,6).
2. A(x, y) за формулами 1.1. Лінії: marching squares.
3. Пошук нулів: сітка стартових точок + метод Ньютона для `B(x, y) = 0`; якобіан чисельний (центральні різниці). Дедуплікація за відстанню. Класифікація за `det J` (`J = ∂B_i/∂x_j`): `det J < 0` це X, `> 0` це O.
4. Сепаратриса: `A = A(X)` (ізолінія, що проходить через X).
5. Для кожної петлі `Φ_lobe = A(O) − A(X)`.

## 3. Демонстрація B: злиття (коалесценція) двох рівних струмів

- Рівні струми I, відстань 2a(t) повільно зменшується (дроти притягуються).
- Потік у кожній петлі «вісімки» (a ≫ ρ): `Φ_lobe ≈ (2I/c)[ln(a/2ρ) + 1/2]`, спадає при зменшенні a.
- Інтерпретація: потік «переходить» із двох окремих петель у спільну зовнішню оболонку (модель злиття магнітних джгутів/плазмоїдів, але без плазми).
- Порівняння двох режимів:
  - **ідеальні (надпровідні) провідники**: потік у кожній петлі зберігається, `Φ_lobe = const`, струми підлаштовуються (злиття заборонене);
  - **з опором**: потік може змінюватися (див. демо C), злиття можливе.
- Реалізація: та сама картина, що в демо A, але з повзунком a і двома режимами. Показати графік `Φ_lobe(a)` на тій самій сторінці.

## 4. Демонстрація C: ідеальне та резистивне коло (аналог вмороженості)

Для замкненого контуру з індуктивністю L (CGS: см) та опором R (с/см):

```
Φ = L I / c
ε = −(1/c) dΦ/dt = I R   ⇒   dI/dt = −(c² R / L) I,   τ = L/(c² R)
```

- **R = 0 (надпровідник):** `Φ = const`, потік заморожений. Це точний аналог теореми Альфвена.
- **R > 0:** потік витікає з постійною часу τ. Це аналог дифузійного доданка `η∇²ψ` в плазмі.
- Для двох зв’язаних контурів: `Φ_k = (L_k I_k + M I_j)/c`. Для ідеальних контурів кожен `Φ_k` сталий, і при наближенні контурів струми змінюються, а топологія зберігається.
- Реалізація: простий графік I(t) і Φ(t) для двох значень R (або одного, що змінюється повзунком), з картинкою двох зв’язаних кілець (схематично). Достатньо 1 невеликої сторінки.

## 5. Демонстрація D: диполь у однорідному полі (модель Данджі, реальна фізика)

Вісесиметрична задача: диполь Землі + однорідне міжпланетне поле B₀ вздовж осі z. Нехай момент диполя спрямований вздовж −z (поле на екваторі направлене на північ, +z), `m > 0`, `B_z0` це поле IMF зі знаком (північне +).

Функція потоку Стокса (`Ψ = ρ A_φ`, ρ циліндричний радіус, `r = √(ρ² + z²)`):

```
Ψ(ρ, z) = ρ² ( B_z0/2 − m/r³ )
B_z = (1/ρ) ∂Ψ/∂ρ,    B_ρ = −(1/ρ) ∂Ψ/∂z
```

Силові лінії Ψ = const (меридіональний переріз).

- **Південне IMF (B_z0 < 0)**: поля скорочуються на екваторі в кільці `r₀ = (m/|B₀|)^{1/3}`: це X-лінія (X-точка в меридіональному перерізі).
- **Північне IMF (B_z0 > 0)**: нулі на осі при `z = ±(2m/B₀)^{1/3}` (каспи), на екваторі нуля немає.
- Для Землі `m ≈ 8,0·10²⁵ Гс·см³`, `B₀ = 5 нТл = 5·10⁻⁵ Гс`: `r₀ ≈ 1,17·10¹⁰ см ≈ 18 R_E` (R_E = 6,37·10⁸ см). Реально ≈ 10 R_E, бо чиста суперпозиція не враховує струми екранування на магнітопаузі (Чепмена-Ферраро). Це варто сказати явно.
- Реалізація: повзунок кута/знака IMF (від +B₀ до −B₀) і величини |B₀|. Показ меридіональних ліній (ізолінії Ψ), позначка X (кільце) та каспів, виділена сепаратриса. Нулі можна знайти аналітично (формули вище).

## 7. Чесні застереження (внести в підписи демо)

1. **Вакуум не має «вмороженості».** Силові лінії там не індивідуальні об’єкти, тому питання «хто з ким з’єднаний» має зміст лише як зміна топології картини. Строга вмороженість з’являється в ідеальному провіднику (плазма, надпровідник), де `E + (v × B)/c = 0`.
2. **2D-ідеалізація:** нескінченні прямі дроти. У реальності замкнені контури, а нулі стають 3D (вісь і площина веєра, λ₁ + λ₂ + λ₃ = 0).
3. **Калібрування:** A визначений з точністю до сталої, фізичні лише різниці потоків (Φ_lobe, E_z(X) − E_z(O)).
4. **Ідеалізація ниток** дає хибну картину «X проходить крізь дріт»: правильно через анігіляцію та народження пар X–O (розд. 2.4).
5. Для рівнянь у демо D не враховано екранування магнітопаузою (розд. 5).

## 8. Додаток: задачі до підручника (короткі відповіді)

1. **Поле двох однакових струмів. Знайти нуль і розклад біля нього.**
   Нуль у центрі, `B ≈ −(4I/ca²)(y, x)`, сепаратриси y = ±x.
2. **Довести, що в вакуумі матриця ∂B_i/∂x_j симетрична й безслідова, класифікувати нулі.**
   rot B = 0 дає симетричність, div B = 0 дає безслідовість; власні числа ±λ (2D) це лише X-точки.
3. **Комплексний метод:** `B_x − iB_y = c·zⁿ`, кількість секторів `2(n+1)`.
4. **Рух частинки в квадруполі B = g(y, x):** фокусування вздовж однієї осі, дефокусування вздовж іншої (принцип подвійної лінзи).
5. **Змінний струм у другому дроті:** знайти `x₀(I₂)`, поріг анігіляції X–O, `Φ_lobe(a)`; обговорити `E_z`.
6. **Надпровідне та резистивне кільце:** `Φ = const` проти `τ = L/(c²R)`.

## 9. Зв’язок з уже зробленою симуляцією перез’єднання (плазма)

У наявній HTML-симуляції розв’язується рівняння індукції для потоку ψ:

```
∂ψ/∂t + v·∇ψ = η∇²ψ,    B = ∇ψ × ẑ
v = (u·x, −u·y),    ψ₀ = δ·ln cosh(y/δ) + b·cos(πx/L)
```

Параметри: u = 0,4; δ = 0,3; b = 0,15; L = 2; область x ∈ [−2; 2], y ∈ [−1; 1]. Там додано поле швидкості, яке стискає струмовий лист, і дифузійний доданок з опором η. Дві теми природно стикуються: вакуумна топологія (цей документ) показує, **коли й як** змінюється картина ліній, а плазмова симуляція показує, **як опір (η) дозволяє це зробити** за наявності вмороженості.
