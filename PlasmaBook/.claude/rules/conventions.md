# Конвенції PlasmaBook

(Зібрано з узгоджень автора листопада 2026. Нові терміни, задачі й розділи оформлюй так само.)

## Скелет розділу
вступний абзац → підрозділи → бокс `Summary` («Головне в розділі») → `\Needspace{9\baselineskip}\tocunnum{Задачі}\section*{Задачі}` + `problem` → бокс `Questions` із `quizlist` (окремого `\section*{Контрольні питання}` немає). На початку файла `\Opensolutionfile{answer}[\currfilebase/\currfilebase-Answers]` + `\Writetofile{answer}{\protect\section*{Розділ~\ref*{<мітка>}. \nameref*{<мітка>}}}` перед `\chapter` (зразок: `Basics/Basics.tex`, рядки 12–13), у кінці `\Closesolutionfile{answer}`.

## Таблиці, рисунки, рамки
- Таблиця: float `table[ht]` + `\centering\small`, `\caption` **угорі**, тіло `platbl` (`\begin{platbl}{colspec={X[l,m]…}}`; синя шапка, сірі непарні рядки). Вища за сторінку: `longtblr[caption=,label=]`. Старі `tabular`/`booktabs` не додавати.
- Рисунок: `\localinput{ім'я.tikz}` з `<Розділ>/tikz/`; `\caption`, `\label` після підпису (`fig:`), посилання в тексті обов'язкове. Імена PGF-функцій унікальні в межах файла.
- Рамки: `Theory` («Нагадаємо…»), `Attention`, `Estimate` («Числова оцінка», зелена; лише для справжніх числових оцінок, не для однорядкової ілюстрації в аргументі і не всередині виведення), `Historical`, `Simulation`, `Summary`, `Questions`.
- Знак після виділеної формули всередині рамки: `\tcbhighmath{a=b.}`.
- Продовження речення після display-формули («де…», «тобто…») без нового абзацу: самотній `%` замість порожнього рядка.

## Задачі
`\begin{problem}\label{prb:Ім'я}\lvl{1..3}` + `\begin{solution}…\end{solution}` усередині; відповіді збирає пакет `answers` у розділ «Відповіді». Мітки унікальні по книзі. Порядок задач = порядок підрозділів. Докладніше: `textbook-problem-author`.

## Навігація й покажчик
- `\index{…}` одразу після терміна; означення `|textbf`; іменні з прізвища («Бома критерій»), решта з іменника з підзаписами («Дифузія!амбіполярна»); діагностика під «Діагностика плазми!…». Подвійні прізвища `Бома--Гросса` (коротке тире без пробілів).
- Заголовки підрозділів із `§` (`\sectionsign`, вимкнено в додатках); номери розділів у тексті лише через `\ref` («розд.~\ref», «§\,\ref», «рис.~\ref»); у «Підсумках» посилання на Словник: `\hyperref[sec:glossary]` + `\pageref`.
- Кінець книги: додатки → Словник термінів → Література → Предметний покажчик. Новий термін: у `Glossary.tex` і покажчик; нові символи в `Notation.tex`.
- Мітки без `new-`; унікальні (`sec:mhd-waves`, `sec:plasma-scales`).

## Мова й терміни
- Терміни: **пересполучення** силових ліній (не «перез'єднання»), **бар'єри перенесення**, **альвенівськ-** (не «альфвенівськ-»), **беззіткнювальний**, **зіткнення**. Зразок термінології: Анісімов.
- ECE (електронно-циклотронне випромінювання) латинкою (при першому вжитку повна англ. назва й «далі скорочено ECE латинськими літерами»); ЕЦР, ІЦР кирилицею.
- Діапазони словами («від 10⁻² до 1»); лапки `\enquote{…}`; `~` після однолітерних слів, перед `\ref/\eqref/\cite`, між числом і одиницею; тире `~---`; десяткова кома `{,}` у математиці; одиниці прямим шрифтом кирилицею.
- Не дублюй виведення дослівно; нагадати результат попереднього розділу можна. Не повторюй преамбулу в першому абзаці. «Саме тому…» без чіткого антецедента не пиши.
- Підтверджене за літературою → одразу `~\cite{ключ}` (англійське джерело з `bibliography.bib`; нема: додай за `textbook-bib-entry`; запис у `books/LOOKUPS.md`). Загальновідоме не цитувати. **Російськомовних джерел у bib не додавати.**

## Правка файлів
Лише Edit/Write; багаторядкові заміни: скрипт Python через Write. **Не `sed`/heredoc** для TeX і кирилиці (псує `\n`, `\b`, `\r`, `\ref`). Шрифти/числа перевіряти скриптом, а не «з голови».

## Плазмова термінологія (єдина по всій книзі; перенесено зі скіла ukrainian-language §7)
Перевіряй за `Glossary.tex`, покажчиком і попередніми розділами; **один термін на одне поняття**; змінювати термін по всій книзі лише з дозволу автора.
- **беззіткнювальна/зіткнювальна** (не безколізійна/колізійна), **зіткнення** (не «колізії»);
- **густина** (маси, заряду) і **концентрація** (частинок, $n$): не плутати; термін для $n$ як у розд. 1;
- **напруженість** поля ($E$, $H$), **магнітна індукція** ($B$), **потік**, **струм**, **провідність**, **тиск**;
- **дрейф**, **дрейфовий центр**, **ларморівський радіус / гірорадіус** (один), **гірочастота / циклотронна частота** (один і той самий, як у розд. 3), **дебаївський радіус** ($\lambda_D$) і **довжина екранування**;
- **затухання Ландау**, **вмороженість**, **нестійкість** (не «нестабільність»), **пересполучення** (магнітне), **довжина вільного пробігу**, **розсіяння**, **випромінювання**, **відсічка**, **резонанс**;
- **хвиля**, **мода**, **гілка**, **дисперсія**, **фазова/групова швидкість**, **показник заломлення**;
- чужі слова без потреби уникай («транспорт» → перенесення, якщо не усталений термін; «ітерація» → наближення/крок; «скейлінг» → масштабування; «трекінг» → стеження).
Новий термін у розділі: одразу в `Glossary.tex` і покажчик (`\index`), у форматі сусідніх записів.

## Параметри задач (перенесено зі скіла problem-author)
Реалістичні параметри плазми (лабораторна, токамак, іоносфера, Сонце): $n$, $T$, $B$ у типових діапазонах, одиниці називай явно («$n=10^{13}~\text{см}^{-3}$», «$T=10$~кеВ»). Однозначність: який $\ln\Lambda$ (задай або «вважайте сталим»), які іони (H, D), $T_e=T_i$ чи ні, які зіткнення враховувати. Ідея задачі: критерій Бома, $N_D$, дрейф, відсічка та подібні.
