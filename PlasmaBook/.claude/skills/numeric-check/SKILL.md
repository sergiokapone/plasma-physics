# Перевірка чисел

Правило книги: **жодне число не потрапляє в текст без перерахунку скриптом**. Помилки, знайдені так: $\tau_d$ корони (≈$3\cdot10^8$ років, не $10^{16}$ с), $k_{iz}$ аргону при 2 і 4 еВ (≈$6\cdot10^{-12}$ і ≈$7\cdot10^{-10}$, відношення ≈120, а не 20), $D_B$ у рецензії, поле квазінейтральності, задача Беннета.

## Інструмент

Python **з `-I`**: `D:\Programs\Programming\WPy64\python\python.exe -I script.py`. Скрипт створюй інструментом **Write** у scratchpad (не heredoc: Bash псує зворотні скісні й кирилицю). Скрипт самодостатній, константи в СГС на початку з коментарем-джерелом:

| величина | значення (СГС) |
|---|---|
| $e$ | $4{,}803\cdot10^{-10}$ ед. СГСЕ |
| $m_e$ | $9{,}109\cdot10^{-28}$ г |
| $m_p$ | $1{,}673\cdot10^{-24}$ г |
| $c$ | $2{,}998\cdot10^{10}$ см/с |
| 1 еВ | $1{,}602\cdot10^{-12}$ ерг ($k_B=1$, $T$ у еВ або ерг; завжди кажи, у чому) |
Використовуй `scipy.constants` лише для звірки.

## Що перевіряти

1. **Estimate-бокси** (`\begin{Estimate}`): кожне число в рядку й підсумок; число значущих цифр відповідає точності вихідних (зазвичай 2).
2. **Числа в тексті**: «≈», «порядку», кратності («у 316 разів»), порядки величин у словесних висновках. Так само діапазони («від … до»).
3. **Відповіді до задач** (`solution`): відтвори розв'язок із **умови задачі**, а не з відповіді; порівняй. Підстав усі варіанти з умови (кілька плазм, кілька $T$).
4. **Таблиці** (`platbl`/`longtblr`): кожен рядок, особливо похідні колонки; єдина система одиниць у колонці.
5. **Ті самі числа в різних місцях**: Estimate ↔ задача ↔ таблиця ↔ шпаргалка (`cheatsheet.tex`) ↔ симуляція (`sims/`). Якщо розходяться, поміч, яке вірне. Задача, що дублює текстовий приклад (як `prb:PlasmaConductivity` — Collisions), — **повідомляй користувачу, не правь мовчки**.
6. **Одиниці й конверсії** СГС ↔ СІ ↔ практичні (еВ, Тл, см⁻³, А): перевір множник переходу окремо, для кожної формули з практичними одиницями (наприклад, $\omega_{pe}=5{,}64\cdot10^4\sqrt{n}$ с⁻¹, $n$ у см⁻³).
7. **Формули з $\ln\Lambda$**: бери за NRL-формуляром (або за таблицею книги `tab:coulomb-log`), а не з пам'яті чи слайда; вказуй, яке $\ln\Lambda$ підставлено.
8. **Типографіка чисел**: десяткова кома `{,}`, `\times10^{n}`, діапазони «від … до» словами, одиниці прямим шрифтом (`\mathrm{с}`, `\mathrm{см}`), секунди кирилицею, не латинською `c`.

## Як працювати

1. Склади перелік чисел для перевірки (grep по `Estimate`, `\approx`, `solution` для розділу).
2. Напиши **один** скрипт, що друкує таблицю «місце | у книзі | перераховано | розбіжність». Не округлюй до порівняння.
3. Розбіжність понад точність округлення (≥ ~5 % або інший порядок) — знахідка. Спершу перевір, чи не різні припущення (інше $\ln\Lambda$, $T$ у кеВ/еВ, $m_i$ = $m_p$ чи $2m_p$); лише тоді правь.
4. Виправляючи число, виправ **усі місця** його вживання (Estimate, відповідь, таблиця, шпаргалка, симуляція) і наступні величини, що від нього залежать.
5. Збір (`build-check`): не запускай дві збірки одночасно (код 12).
6. Не комітити, поки користувач не попросить.

## Звіт

Таблиця: `файл:рядок` | у книзі | перераховано | вердикт (збігається / розбіжність / інші припущення) | виправлено чи ні. Нижче: припущення скрипта (константи, $\ln\Lambda$), розташування скрипта. Якщо все збіглося — «числа збігаються», без вигаданих правок.
