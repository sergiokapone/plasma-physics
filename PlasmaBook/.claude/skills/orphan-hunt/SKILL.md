# Сироти й розриви сторінок

## 1. Подивитись, а не вгадувати

1. Збірка: `powershell -File build.ps1`.
2. Номер сторінки з PDF = номер у видачі `pdftoppm`/`pdftotext` (рахується від 1, включно з титулом). Нумерація, надрукована на сторінці, може відрізнятись.
3. Рендер: `pdftoppm -f N -l N -r 50 -png main.pdf <scratchpad>/pg` і Read картинки. Дешевий тест на «майже порожню сторінку»: `pdftotext -f N -l N main.pdf - | wc -l` (кілька рядків = підозра), але кирилиця у виводі ламається, тому зміст дивитись лише на картинці.
4. Огляди сусідніх сторінок (N−1, N+1): сирота зазвичай — хвіст абзацу/списку з попередньої сторінки.

## 2. Лікування від найменшого втручання

1. **Скоротити текст** одного-двох пунктів на попередній сторінці так, щоб звільнити 1–2 рядки (це не змінює змісту; не чіпати клас). Так виправили с. 205 розд. «Масштаби»: скоротили контрольні питання 8 і 12. Перевір після кожної спроби — рядки перетікають, і сирота може перескочити на іншу сторінку.
2. Якщо скорочувати нема чого — точкова правка розміщення в `.tex`: `\Needspace{N\baselineskip}` перед блоком (у проєкті вже використовується), `\nopagebreak`, зміна порядку.
3. Системні проблеми (однаково для всіх розділів) — на рівні `ConspectBook.cls`: `\widowpenalty`/`\clubpenalty`, `\Needspace` у `\pretocmd{\section}`/`\subsection`. Для цього є агент `typesetter`; сам клас без потреби не чіпати, бо це зсуває всю книгу.
4. Після правки текст і зсув перераховуються: розділи далі змінюють сторінки; перевір кінець розділу й початок наступного.

## 3. Чого не робити

- Не додавати `\vspace{-…}` і не стискати поля заради одного рядка.
- Не «лікувати» сироту, додаючи текст у розділ (правило: розділ не довшає).
- Не покладатись на Overfull-журнал: сирота там не видна, дивитись лише PDF.

## 4. Звіт

Назвати сторінку до й після, що саме скорочено, і підтвердити перевіркою картинки, що сирота зникла й не з'явилась нова.
