# Збірка і перевірка журналу

## Збірка

`powershell -NoProfile -File build.ps1` (`-Clean` чистить допоміжні файли; `-Chapter <Розділ>` збирає лише один розділ у `_chapters/<Розділ>.pdf` через `test.tex`, посилання на інші розділи там «??» — це норма; для перевірки одного розділу брати саме його). Усередині `latexmk -lualatex` + biber. **Ніколи** не `pdflatex` і не `latexmk -pdf`: дає хибні помилки (`\mittheta`, `\symbf`) і може зіпсувати `main.pdf`. Збірка займає хвилину-дві; для довгої ставити `timeout` 600000 мс.

Кінець видачі скрипта: `latexmk exit code: 0` — норма. Ненульовий код (наприклад 12) — є помилка, шукати нижче.

## Правило: яку збірку коли

- **Перевірка/правка одного розділу** (верстка, читка) — лише `build.ps1 -Chapter <Розділ>`; всю книгу не збирати.
- **Повна збірка** — наприкінці серії правок або коли користувач просить. Після неї **завжди** перевірити `sieve.txt`/`main.log` на биті посилання й цитати (`undefined`, `multiply defined`, `Label(s) may have changed`): у повній збірці їх не повинно бути жодного (шрифтові `Font shape ... undefined` StixTwoMath — давній фон, ігнорувати). У `-Chapter`-збірці «??» для інших розділів — норма.
- Верстку (layout-checker, typesetter) перевіряти лише коли користувач просить.

## Що перевіряти

```
grep -n "^!" main.log                         # помилки TeX (мають бути порожні)
grep -n "Citation.*undefined\|Reference.*undefined\|undefined control" main.log
grep -n "Package biblatex Warning\|Missing character" main.log
```

- Помилка в `main.toc:NN` означає збій у записі змісту (наприклад, неправильне визначення в `\titlecontents`); подивитись рядок у `main.toc`.
- Biber-помилки: у `main.blg`. Файли `main.bbl-SAVE-ERROR`/`main.bcf-SAVE-ERROR` — наслідок збою, не комітити.
- **Overfull:** у книзі стабільно близько ста Overfull-повідомлень (рахунок ~100–104 — звичайний фон). Це дефект лише якщо переповнення > 10 пт або воно в новому місці; не «лікувати» дрібні 1–5 пт.
- `sieve.txt` (вивід texlogsieve) записано в UTF-16, тому прямий `cat` показує літери з пробілами; дивитись `main.log` або читати як UTF-16.

## Порядок підозр при помилці

1. Остання правка (клас, нова врізка, таблиця) — відкотити подумки й подивитись, що зламалось.
2. Спецсимвол у `.bib` (`&`, `_`, `%`, кирилиця без `langid`).
3. Аргумент макросу з порожнім значенням (було: `\toc@sign` з порожнім номером).
4. Правки класу робити Edit/Write, не `sed`/heredoc (Bash псує зворотні скісні).

## Після збірки

Подивитись зміни у PDF, якщо правка видима: `pdftoppm -f N -l N -r 60 -png main.pdf <scratchpad>/x` і Read картинки. Журнал чистий ≠ вигляд правильний.
