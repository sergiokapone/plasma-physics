# Перевірка HTML-версії

Виконувати після `build-html` і публікації. Звітує без правок; виправлення — через скіл `html-class`/агента `html-typesetter`.

## 1. Збірка чиста

- `texlogsieve main-html_html.log` (або `grep -n "^!" … | head`): жодних `^!`. Журнали цілком не читати.
- `build-error.txt` (якщо є): перша помилка LaTeX і файл, у якому вона сталась.
- Не втрачені посилання/цитати: `undefined`, `multiply defined` у `main-html_html.log`. Відомий фон — шрифтові попередження.

## 2. Формули (найчастіше ламається)

```
node tools/check-mathjax-html.js docs/ch*.html
```
Список формул, які MathJax не прочитав (невизначений макрос, `\tcbhighmath`, `\mitomega`, нерозібрана ліґатура). Виправляти макроси в `mathjax2lwarp.py` (`ALWAYS`/`OVERRIDES`), не в HTML.

Ознаки поломок у самому тексті сторінки: `^` перед `<`, `/>`, `//` або в формулі (ліґатури шрифту: перевірити `RawFeature={-calt,-liga}`), `??` на місці посилань, порожні номери рівнянь (`\tag{\theequation}`), довга display-формула, що вилазить за ширину (її має розбивати `book.js`).

## 3. Посилання й файли

- Усі `src=`/`href=` у `docs/*.html` ведуть на наявні файли (`publish_html.py` сам копіює потрібні; перевірити скриптом: пройти атрибути, `os.path.exists`, порівняння регістру імен: GitHub Pages чутливий до регістру, Windows ні).
- Картинки: SVG відкриваються й не порожні; розмір (великі SVG > 5 МБ — кандидати на PNG).
- Посилання «задача ↔ відповідь», `\ref` між розділами (різні сторінки: `ch3.html#…`).
- `index.html` (лендінг) і HTML-книга: кнопка «Читати онлайн» веде в наявну сторінку (`main-html.html`/`docs/…`).

## 4. Вигляд (Playwright, не headless chrome `--window-size`)

Зробити скриншоти (див. пам'ятку про симуляції: мінімальна ширина вікна headless Chrome 500):
- десктоп 1100×900, телефон 390×800;
- світла й темна тема (`html.dark`);
- сторінки: титульна (`main-html.html`), найкоротший розділ, розділ із таблицею й tikz-малюнком, «Відповіді», «Додатки», «Література».
Дивитися на: бічний зміст (розгортає лише поточний розділ), кнопки «попередній/наступний», блоки `cb-*` (Theory, Estimate, Summary, Questions, задачі), таблиці (справжні `<table>`, а не зображення), рисунки (не обрізані, не величезні), горизонтальний скрол на телефоні (його бути не повинно), консольні помилки (`page.on('console')`, `pageerror`).

Скриптом перевіряти overflow: `document.documentElement.scrollWidth <= window.innerWidth` на телефоні.

## 5. Відповідність PDF

Вибірково (2–3 розділи): ті самі підрозділи в тому ж порядку, формули й числа збігаються, нічого не втрачено (порівняти зміст `main.toc` зі змістом сторінки), таблиці мають усі рядки. Властивості HTML (немає номерів сторінок, `\Needspace`, обгортання тексту навколо рисунка) — не дефекти.

## 6. Звіт

Коротко, українською: що перевірено, що зламано (розділ, елемент, симптом, ймовірна причина: клас / prepare / publish / CSS), що вважаємо властивістю HTML. Нічого не коміттити без прохання.
