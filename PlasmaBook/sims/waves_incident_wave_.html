Електромагнітна хвиля, що падає з вакууму на шар плазми

Розд. 2.2–2.3, рис. 2.2, ф-ли (2.3), (2.5)

Режими

Параметри

Величини

Що спостерігати

  1. ω > ωp: ε > 0, хвиля заходить у плазму з довшою довжиною хвилі λ = 2πc/√(ω² − ωp²). Відбивається лише мала частка (формула Френеля), у вакуумі видно слабку стоячу хвилю.
  2. ω < ωp: ε < 0, показник заломлення уявний. Поле спадає як e−κx, κ = √(ωp² − ω²)/c (штрихова крива), енергії в плазмі немає. Відбиття повне: у вакуумі чітка стояча хвиля з вузлами й пучностями.
  3. Зменшуйте товщину шару при ω < ωp: поле просочується крізь шар (тунелювання), з’являється пройшла хвиля, R падає, а R + T = 1.
  4. Наближайте ω до ωp: довжина хвилі в плазмі й глибина проникнення розбігаються, R швидко змінюється на кривій праворуч.
  5. Зіткнення ν поглинають хвилю: R + T < 1. Плавний профіль густини зменшує відбиття при ω > ωp, але не скасовує його при ω < ωp.

Одновимірне числове розв’язання рівнянь Максвелла (метод скінченних різниць у часовій області, FDTD), c = 1, СГС: ∂tB = −∂xE, ∂tE = −∂xB − 4πj, струм електронів ∂tj = ωp²(x)E/4π − νj. Крок сітки 1, крок часу 0,95, c/ωp = 10 комірок. Падаюча хвиля одиничної амплітуди вводиться в точці ліворуч методом повного й розсіяного поля, тож усе, що лишається ліворуч від неї, є відбитою хвилею. Поле на екрані — сума падаючої й відбитої. Справа стоїть поглинач.

Виміряне R = (Emax − Emin)/(Emax + Emin) за огинаючою стоячої хвилі у вакуумі, виміряне T — квадрат амплітуди за шаром. Теорія: формули Френеля для різкого шару з ε = 1 − ωp²/[ω(ω + iν)]. Для плавного профілю теорії немає, лише вимір.
