Що спостерігати

  1. Частинка відбивається там, де B = B0/sin²θ0: виміряне zm збігається з теорією (штрихові лінії).
  2. У площині швидкостей точка рухається по колу |v| = const; відбиття — це точка v∥ = 0.
  3. Режим «Порушення адіабатичності»: μ стрибає в горловинах, пітч-кут блукає, і частинка може потрапити в конус втрат.
  4. Більше R звужує конус: θc = arcsin(1/√R), частка втрат ізотропного розподілу 1 − √(1 − 1/R).

Схема Боріса, крок Δt = 0,08/(Rωc0): у статичному B енергія зберігається точно, μ — лише адіабатично. Поле параксіальне: Bz(z) = B0[1 + (R−1)sin²(πz/2L)], Br = −(r/2)dBz/dz (div B = 0 точно, rot B ∝ r/L²). Одиниці: q/m = B0 = 1, довжини в v0/ωc0.
